# 🦙 LlamaIndex_PT

This repository contains my **initial practice and experimentation with LlamaIndex**.  
It includes basic workflows for document parsing, chunking, and vector store indexing as part of learning Retrieval-Augmented Generation (RAG).

---

## 📌 Project Purpose

This directory is created for:

- Understanding LlamaIndex fundamentals
- Practicing document ingestion & chunking
- Building and querying vector indexes
- Exploring basic RAG pipelines

This is a learning-focused repository.

---

## 📂 Repository Structure

| File | Description |
|------|-------------|
| `Document_parser and Chunking.ipynb` | Parsing documents and splitting them into chunks |
| `Vector_store_indexing.ipynb` | Creating vector indexes and querying them |
| `.env` (ignored) | Stores API keys locally (not committed) |

---

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/DeepikaDG2310/LlamaIndex_PT.git
cd LlamaIndex_PT
```
2️⃣ Create Virtual Environment
```bash
python -m venv .venv
```
Windows:
```bash
.venv\Scripts\activate
```
Linux/MAC:
```bash
source venv/bin/activate
```

3️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```
